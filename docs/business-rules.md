# 呼び判定・売上集計ルール（確定版）

- 確定日: 2026-11-08（オーナー確認済み）
- 実装: `gas/Invitation.js`（判定・集計）、`gas/StaffOps.js`（来店・会計）
- 設定値: Script Properties で変更可（括弧内は既定値）

## 1. 呼び判定

来店登録の時点で、サーバー時刻とサーバーに記録された予約情報だけを使って判定する。

| 条件（上から順に評価） | 判定 | 理由コード |
|---|---|---|
| 予約なしの来店 | 店客 | `no_reservation` |
| 顧客が LINE から予約（希望キャストの有無に関係なく） | 店客 | `customer_line_reservation` |
| オーナー・スタッフが登録した予約（店舗受付） | 店客 | `store_reservation` |
| 予約登録が来店登録より後 | 店客 | `reserved_after_checkin` |
| 予約が変更されている（version ≠ 1） | 要確認 | `reservation_modified` |
| 担当キャスト以外が登録した予約 | 要確認 | `registered_by_other` |
| 担当キャストが無効・キャスト以外 | 要確認 | `cast_inactive` |
| 担当キャスト本人が来店登録 | 要確認 | `self_checkin` |
| 予約登録から来店登録まで **30分未満**（`REVIEW_THRESHOLD_MINUTES`） | 要確認 | `registered_shortly_before` |
| 上記以外のキャストの事前予約 | **呼び** | `cast_reservation` |

- キャストが登録する予約の担当キャストは、ログイン中のキャスト本人に固定される（画面から選ばせない）。
- 要確認は、オーナーが「呼び」または「店客」に変更して確定する。変更には理由が必須で、変更前後を監査ログに記録する。
- 来店登録できるのは現在の営業日の予約のみ。1つの予約で来店登録できるのは1回。

## 2. 営業日

- 切り替え時刻は **午前6時**（`BUSINESS_DAY_CUTOFF_HOUR`）。2026-11-08 03:00 の来店は 2026-11-07 営業日。
- 会計は、会計した時刻ではなく **来店の営業日** に計上する（深夜の会計も同じ営業日）。

## 3. 売上集計

- **店舗総売上** = その営業日の会計総額の合計（取消を除く）
- 内訳: **呼び売上**（判定が呼び）＋ **店客売上**（店客）＋ **要確認**（オーナー判定前）
- 呼び売上は総売上の内訳であり、別売上として加算しない。

## 4. 日払い

- 対象: 判定が **呼び** の来店の会計
- 計算: キャストごとに `Σ(会計総額 × 日払い率) ÷ 100` を **1円未満切り捨て**
  - 会計総額は **キャストドリンク代を含む**
  - 日払い率は **10%**（`PAYOUT_RATE_PERCENT`）。会計登録時の率を `Transactions.payout_rate` に保存し、後で率を変えても過去分は変わらない
  - 切り捨てはキャストごとの合計に対して1回（会計ごとには切り捨てない）
- 要確認の来店は、オーナーが呼びに確定するまで日払いに含めない。
- 日払いの確定（`payout_amount`、`finalized_*` の記録）はフェーズ3。

## 5. 閲覧範囲

| | owner | staff | cast |
|---|---|---|---|
| 予約一覧 | 全件 | 全件 | 自分が登録した予約のみ |

| 日次集計 | 全体 | 全体 | 自分の呼び売上・日払い予定のみ |
| 会計登録 | ○ | ○ | × |
| 判定の変更 | ○ | × | × |
